# 🐾 Pet Adoption Website

A modern pet adoption platform where users can explore, post, and adopt pets responsibly.  
The platform helps connect pet lovers with pets in need of a caring home.

---

## 🚀 Features

- 🔐 User Authentication
- 🐶 Add Pets for Adoption
- 📍 Location-Based Pet Details
- 📋 Pet Listings & Details
- ❤️ Easy Adoption Process
- 📱 Responsive UI Design

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Dharshini-8/Pet-Adoption-Website.git
```

### Install Dependencies

```bash
npm install
```

### Run Frontend

```bash
npm start
```

### Run Backend

```bash
node server.js
```
